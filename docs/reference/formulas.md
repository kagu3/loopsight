# 式の書き方

ストックの初期値、フローの流量、変数の値は、式で書きます。このページは、その書き方をまとめたものです。AI が書いた式を読むときや、ビューアで式を直すときに使います。

式を計算するのは、Insight Maker 公式のエンジン [`simulation`](https://github.com/scottfr/simulation) です。書き方はエンジンの決まりのとおりです。このページには、よく使うものだけを載せています。

## このページの例について

例は、次の小さなモデルの変数「例」の式として動かしています。

| 要素 | 種類 | 式 |
|---|---|---|
| 人口 | ストック | 初期値 `100` |
| 出生率 | 変数 | `0.1` |
| 出生 | フロー（人口に入る） | `[人口] * [出生率]` |

シミュレーションの設定は、開始 0、期間 10、刻み幅 1、時間の単位は年です。人口は 100、110、121、… と毎年 1 割ずつ増えます。「例の値」は、このモデルで動かしたときの値です。

このページの例は、テスト（`tests/docs-formulas.test.ts`）で実際に動かしています。エンジンを更新して動かなくなった例があれば、テストが失敗します。

## 式の基本

### 数と演算子

数は `42`、`3.14`、`1.2e-5`（1.2×10⁻⁵）のように書きます。

| 演算子 | 意味 | 例 | 例の値 |
|---|---|---|---|
| `+` `-` `*` `/` | 足す、引く、掛ける、割る | `10 / 4` | 2.5 |
| `^` | べき乗 | `2^3` | 8 |
| `mod`、`%` | 割った余り | `10 mod 3` | 1 |
| `=` `<>` `<` `<=` `>` `>=` | 比べる（`<>` は「等しくない」。`!=` も使える） | `[人口] <> 100` | 0 年は 0、そのあとは 1 |
| `and` `or` `not` | かつ、または、ではない | `IfThenElse([人口] > 150 and Years() < 8, 1, 0)` | 5〜7 年だけ 1 |

計算の順番はふつうの算数と同じで、`1 + 2 * 3` は 7 です。順番を変えるときは `( )` で囲みます。

比べた結果は、正しければ 1、正しくなければ 0 として残ります。

### ほかの要素を参照する

ほかの要素の値は `[名前]` で使います。

| 例 | 例の値 |
|---|---|
| `[人口]` | 100、110、121、… |
| `[出生率] * 2` | 0.2 |
| `-[人口]` | −100、−110、−121、… |

- 名前は大文字と小文字を区別しません。`[Birth Rate]` と `[birth rate]` は同じ要素です
- 名前は要素の名前のとおりに書きます。`[出生率 ]` のように前後に空白を入れると、エンジンが要素を見つけられません
- 参照するには、参照される要素から式の要素へのリンク（点線の矢印）が要ります。AI の `upsert_elements` とビューアの編集は、足りないリンクを自動で足します
- 自分自身は参照できません。ストックの今の値から次の値を決めたいときは、フローを使います
- 変数どうしが互いに参照し合う（A が B を使い、B が A を使う）と、`Circular equation loop identified` という誤りになります。どこかにストックを入れて、ループを切ります

### コメント

式の中に、計算に使わない説明を書けます。

```
[人口] * 0.5 # 半分にする
```

`#` か `//` から行の終わりまでがコメントです。`/* … */` で囲むと、何行でもコメントにできます。

### 何行かに分けて書く

長い条件は、`if … then … else … end if` で何行かに分けて書けます。最後に計算した値が式の値になります。

```
if Years() < 2 then
  10
else if Years() < 3 then
  20
else
  30
end if
```

途中の値に名前を付けるときは `<-` を使います。名前はその式の中でだけ使えます。

```
半分 <- [人口] * 0.5
半分 + 1
```

## 時間

| 関数 | 意味 | 例 | 例の値 |
|---|---|---|---|
| `Years()` | いまの時刻を年で表した数 | `Years()` | 0、1、2、…、10 |
| `Months()` `Weeks()` `Days()` `Hours()` `Minutes()` `Seconds()` | いまの時刻を、それぞれの単位で表した数 | `Days()` | 0、365、730、… |
| `Time()` | いまの時刻（単位つき） | `IfThenElse(Time() > {5 Years}, 1, 0)` | 6 年から 1 |
| `TimeStart()` | 開始の時刻（単位つき） | `TimeStart() / {1 Years}` | 0 |
| `TimeStep()` | 刻み幅（単位つき） | `TimeStep() / {1 Years}` | 1 |
| `TimeLength()` | 期間（単位つき） | `(Time() - TimeStart()) / TimeLength()` | 0、0.1、0.2、…、1 |
| `TimeEnd()` | 終わりの時刻（単位つき） | `(TimeEnd() - Time()) / {1 Years}` | 10、9、8、…、0 |

- `Years()` などは、ただの数を返します。時間の単位が月のモデルでも使えて、12 か月目の `Years()` は 1 です
- `Time()` などは、`{5 Years}` のような単位つきの値を返します。そのまま単位のない変数の値にしたり、ただの数と比べたりすると誤りになります。`Time() > 5` ではなく、`Time() > {5 Years}` か `Years() > 5` と書きます。単位のない数がほしいときは、`{1 Years}` のような単位で割ります
- 開始の時刻を 2020 にすると、`Years()` も 2020 から数えます
- 式は刻み幅ごとに計算します。刻み幅が 1 年なら、時刻 0、1、2、… でだけ値が決まり、その間の値はありません。`Step` などで値が変わる時刻も、刻みの時刻にそろいます

## よく使う関数

関数の名前は大文字と小文字を区別しません（`IfThenElse` と `ifthenelse` は同じ）。このページでは、エンジンの文書と同じ書き方にそろえています。

`{2 Years}` のような時間の長さは、単位を付けずに `2` と書いても動きます。そのときはモデルの時間の単位（このページの例では年）で数えます。単位を付けておくと、あとで時間の単位を変えても意味が変わりません。

### 条件

| 関数 | 意味 | 例 | 例の値 |
|---|---|---|---|
| `IfThenElse(条件, 正しいとき, 正しくないとき)` | 条件で値を選ぶ | `IfThenElse(Years() > 5, 1, 0)` | 6 年から 1 |
| `Max(a, b)`、`Min(a, b)` | 大きい方、小さい方。値に上限や下限を付けるのに使う | `Max(0, 50 - [人口] * 0.2)` | 30 から減って、10 年で 0 で止まる |
| `Stop()` | シミュレーションをそこで終える | `IfThenElse(Years() >= 3, Stop(), 0)` | 0。結果は 2 年までになる |

### 数学

| 関数 | 意味 | 例 | 例の値 |
|---|---|---|---|
| `Round(x)` `Floor(x)` `Ceiling(x)` | 四捨五入、切り捨て、切り上げ | `Round(3.14159 * 100) / 100` | 3.14 |
| `Abs(x)` | 絶対値 | `Abs(-3)` | 3 |
| `Sqrt(x)` | 平方根 | `Sqrt(16)` | 4 |
| `Exp(x)` `Ln(x)` `Log(x)` | e の x 乗、自然対数、常用対数 | `Exp(-1)` | 0.368 |
| `Max(…)` `Min(…)` `Sum(…)` `Mean(…)` | 最大、最小、合計、平均。いくつでも渡せる | `Mean(1, 2, 3)` | 2 |
| `Sin(x)` `Cos(x)` `Tan(x)` | 三角関数（ラジアン） | `Sin(pi / 2)` | 1 |
| `pi`、`e` | 円周率、ネイピア数 | `pi` | 3.14159 |

### 入力の形を作る

政策を入れた時刻や、一度だけの出来事を表すのに使います。

| 関数 | 意味 | 例 | 例の値 |
|---|---|---|---|
| `Step(始まり, 高さ)` | 始まりの時刻から、値が高さになる | `Step({3 Years}, 5)` | 0〜2 年は 0、3 年から 5 |
| `Pulse(時刻, 高さ, 幅, 繰り返し)` | 時刻から幅の間だけ高さになる。幅と繰り返しは省ける | `Pulse({2 Years}, 5, 1)` | 2、3 年だけ 5 |
| | 繰り返しを付けると、その間隔で何度も出る | `Pulse({1 Years}, 3, 0, {4 Years})` | 1、5、9 年に 3 |
| `Ramp(始まり, 終わり, 高さ)` | 始まりから終わりまでに、0 から高さへまっすぐ上がる | `Ramp({2 Years}, {6 Years}, 8)` | 3 年 2、4 年 4、…、6 年から 8 |
| `Seasonal(山の時刻)` | 1 年で 1 回りする波（−1〜1）。山の時刻は省ける | `Seasonal({6 Months})` | 刻み幅が 1 年だと毎回同じ値。時間の単位が月のモデルで使う |

### 乱数

実行するたびに値が変わります。比べるときは、何回か実行して見ます。

| 関数 | 意味 | 例 |
|---|---|---|
| `Rand(最小, 最大)` | 一様分布。省くと 0〜1 | `Rand(1, 10)` |
| `RandNormal(平均, 標準偏差)` | 正規分布 | `RandNormal(100, 10)` |
| `RandLognormal(平均, 標準偏差)` | 対数正規分布 | `RandLognormal(1, 0.5)` |
| `RandBoolean(確率)` | その確率で 1、そうでなければ 0 | `RandBoolean(0.5)` |
| `RandBinomial(回数, 確率)` | 二項分布 | `RandBinomial(10, 0.5)` |
| `RandPoisson(平均)` | ポアソン分布 | `RandPoisson(3)` |
| `RandTriangular(最小, 最大, 最頻値)` | 三角分布 | `RandTriangular(0, 10, 3)` |
| `RandExp(率)` | 指数分布 | `RandExp(2)` |
| `Fix(値, 期間)` | 値を期間の間だけ固定する。期間を省くと最後まで固定する | `Fix(Rand(), {5 Years})` |

刻みごとに新しい乱数が出ます。`Fix(Rand(), {5 Years})` は、5 年ごとに新しい乱数にします。

### 遅れと平滑化

発注してから届くまで、気づいてから動くまでのように、時間がたってから効くつながりを表します。

| 関数 | 意味 | 例 | 例の値 |
|---|---|---|---|
| `Delay(値, 長さ, 初めの値)` | 長さだけ前の値。まだ前の値がない間は初めの値（省くと開始の時刻の値） | `Delay([人口], {2 Years}, 50)` | 50、50、100、110、121、… |
| | 初めの値を省くと、開始の時刻の値を使う | `Delay([人口], {2 Years})` | 100、100、100、110、121、… |
| `Delay1(値, 長さ, 初めの値)` | 1 次の遅れ。なだらかに追いつく | `Delay1([出生], {2 Years})` | 10、10、10.5、11.3、… |
| `Delay3(値, 長さ, 初めの値)` | 3 次の遅れ。しばらく変わらず、そのあと追いつく | `Delay3([人口], {6 Years})` | 100、100、100、100、101.25、104.5、109.95、… |
| `DelayN(値, 長さ, 次数, 初めの値)` | 次数を決めた遅れ | `DelayN([人口], {6 Years}, 2, 100)` | 100、100、100、101.11、103.81、… |
| `Smooth(値, 長さ, 初めの値)` | 平滑化（指数平滑）。長さが長いほどゆっくり追う | `Smooth([人口], {3 Years}, 50)` | 50、66.7、81.1、… |
| `SmoothN(値, 長さ, 次数, 初めの値)` | 次数を決めた平滑化 | `SmoothN([人口], {3 Years}, 2)` | 100、100、100、104.4、… |

- 初めの値は、どれも省けます
- 1 つ目の引数は、ふつう `[名前]` にします
- 遅れの長さ（`Delay3` と `DelayN` では長さを次数で割ったもの）が刻み幅に近いと、値が揺れたり、ぎざぎざになったりします。たとえば刻み幅 1 年で `Delay3([人口], {2 Years})` は、133.75、120.25、156.03、… と上下します。刻み幅を 0.25 年にすると、なめらかに増えます
- 図の遅れの印（‖）は見た目だけで、計算には効きません。実際の遅れは、ここの関数で表します

### 過去の値

| 関数 | 意味 | 例 | 例の値 |
|---|---|---|---|
| `PastMax(値, 期間)` `PastMin(値, 期間)` | これまでの最大、最小。期間を付けると、その長さだけさかのぼる | `PastMin([人口], {3 Years})` | 100、100、100、100、110、121、… |
| `PastMean(値, 期間)` `PastMedian(値, 期間)` `PastStdDev(値, 期間)` | これまでの平均、中央値、標準偏差 | `PastMean([人口], {2 Years})` | 100、105、110.3、… |
| `Fix(値)` | 初めの値のまま固定する | `Fix([人口])` | 100 |

### 表関数（コンバーター）

グラフの点をつないだ形で、入力から出力を決めるときに使います。2 つの書き方があります。

1 つ目は、コンバーターの要素を作る書き方です。表（`behavior.data` の `[[入力, 出力], ...]`）を持ち、入力は時刻（`input: "TIME"`）か、ほかの要素（`input: "ELEMENT"` と `input_element`）です。`interpolation` が `"LINEAR"` なら点の間をまっすぐつなぎ、`"NONE"` なら次の点まで同じ値です。ほかの要素の式からは `[名前]` で参照します。

```json
[
  { "type": "CONVERTER", "name": "価格表", "behavior": { "input": "TIME", "data": [[0, 10], [2, 30], [4, 20]], "interpolation": "LINEAR" } },
  { "type": "VARIABLE", "name": "例", "behavior": { "value": "[価格表] * 2" } }
]
```

価格表は 10、20、30、25、20 と変わり、最後の点（4 年）からあとは 20 のままです。例はその 2 倍になります。

入力にほかの要素を使うときは、その要素からコンバーターへのリンクも足します。リンクがないと、`Converter input element "人口" is not connected to the converter "混み具合".` という誤りになります。

```json
[
  { "type": "CONVERTER", "name": "混み具合", "behavior": { "input": "ELEMENT", "input_element": "人口", "data": [[100, 1], [200, 0.5]], "interpolation": "LINEAR" } },
  { "type": "LINK", "from": "人口", "to": "混み具合" }
]
```

混み具合は 1、0.95、0.895、… と下がり、人口が表の最後の点（200）を超えると 0.5 のままです。

2 つ目は、式の中に表を書く `Lookup(入力, 入力の並び, 出力の並び)` です。点の間はまっすぐつなぎます。

| 例 | 例の値 |
|---|---|
| `Lookup(6, {5, 7}, {10, 15})` | 12.5 |
| `Lookup(Years(), {0, 5, 10}, {0, 100, 50})` | 0、20、40、60、80、100、90、80、70、60、50 |

## 単位

### 単位の書き方

単位つきの数は `{5 Meters}` のように、`{ }` の中に数と単位を書きます。要素の単位は、要素の `units`（ビューアの「単位」）に書きます。

- 単位の名前は大文字と小文字を区別しません。`Meter` と `Meters` のように、複数形でも書けます
- 掛け算は `*`、割り算は `/` か `per`、べき乗は `^` で書きます（`{9.81 Meters/Second^2}`、`{60 Kilometers per Hour}`）
- 長さ、重さ、時間などのよく使う単位は、エンジンが知っていて、同じ種類の単位どうしなら変換します。`Kilometers` と `Meters` を足したり、`Hours` から `Minutes` を引いたりできます
- エンジンが知らない名前も単位にできます（`{3 Widgets}`、`{3 人}`）。同じ名前どうしで使います。知らない名前では複数形は別の単位になり、`Widget` と `Widgets` は足せません

| 例 | 要素の単位 | 例の値 |
|---|---|---|
| `{5 Meters} + {10 Centimeters}` | `Meters` | 5.1 |
| `{5 Meters}` | `Centimeters` | 500 |
| `{1 Hour} - {30 Minutes}` | `Minutes` | 30 |
| `{60 Kilometers per Hour}` | `Meters/Second` | 16.67 |
| `{3 人} * 2` | `人` | 6 |
| `Time()` | `Years` | 0、1、2、… |
| `Time()` | `Months` | 0、12、24、… |

要素に単位があるとき、式が単位のない数（`5` など）なら、要素の単位が付いているものとして扱います。

### ストックとフローの単位

フローの単位は、ストックの単位を時間の単位で割ったものにします。ストックが `Widgets` なら、フローは `Widgets/Year` や `Widgets/Month` です。フローの単位の時間がモデルの時間の単位と違っても、エンジンが変換します（時間の単位が年のモデルで `2` `Widgets/Month` のフローは、1 年で 24 増やします）。

```json
[
  { "type": "STOCK", "name": "在庫", "behavior": { "initial_value": "10", "units": "Widgets" } },
  { "type": "VARIABLE", "name": "入荷率", "behavior": { "value": "0.1", "units": "1/Year" } },
  { "type": "FLOW", "name": "入荷", "to": "在庫", "behavior": { "value": "[在庫] * [入荷率]", "units": "Widgets/Year" } }
]
```

ストックに単位があって、フローの単位がない（または時間で割っていない）と、`Incompatible units for flow [入荷] and connected stock [在庫].` という誤りになります。

### 単位が合わないときの誤り

単位が合わないと、モデルを実行するときに、エンジンが英語で誤りを返します。よく出るものは次のとおりです。

| 誤りになる式 | 要素の単位 | 出る誤り | 直し方 |
|---|---|---|---|
| `{5 Meters}` | なし | `Wrong units generated for [例]. Expected no units and got Meters.` | 要素の単位を `Meters` にする |
| `{5 Seconds}` | `Meters` | `Wrong units generated for [例]. Expected Meters, and got Seconds.` | 式か要素の単位を直す |
| `{1 Meter} + {1 Second}` | なし | `Incompatible units for the addition of Meter and Second.` | 種類の違う単位は足し引きできない。式を見直す |
| `{5 Meters} + 1` | `Meters` | `Incompatible units for the addition of Meters and unitless.` | `{5 Meters} + {1 Meters}` のように、足す数にも単位を付ける |
| `{3 Widgets} + {2 Widget}` | `Widgets` | `Incompatible units for the addition of Widgets and Widget.` | どちらかの名前にそろえる |
| `Time() > 5` | なし | `Incompatible units for the comparison of Years and unitless.` | `Time() > {5 Years}` か `Years() > 5` にする |

`Wrong units generated` は「式の結果の単位が、要素の単位と違う」、`Incompatible units` は「式の中で、単位の合わないものどうしを計算した」という意味です。単位の掛け算、割り算は自由で、足し算、引き算、比べるときにだけ単位をそろえます。たとえば `[在庫] * [入荷率]` は、入荷率に単位がないと `Widgets` になり、フローの `Widgets/Year` と合いません。入荷率の単位を `1/Year` にすると合います。

## ストック、フロー、変数の違い

どれも同じ書き方の式を使えます。違うのは、いつ計算して、何を表すかです。

| | 式 | いつ計算するか | 表すもの |
|---|---|---|---|
| ストック | 初期値（`initial_value`） | 始まりに 1 回だけ | 始まりの量。そのあとはフローで増減する |
| フロー | 流量（`value`） | 刻みごと | 時間の単位あたりの量（年の単位なら 1 年あたり） |
| 変数 | 値（`value`） | 刻みごと | そのときの値 |

- **ストックの初期値：** 始まりに 1 回だけ計算し、その値から始めます。ほかのストックや変数、フローを参照できます（`[人口] / 2` など）。`Years()` は開始の時刻、`Rand()` はその 1 回の乱数になります。`Step` や `Delay` のような時間で変わる関数を書いても、始まりの時刻の値にしかなりません
- **フローの流量：** 1 刻みでストックが変わる量は「流量 × 刻み幅」です。流量が 10（1 年あたり）で刻み幅が 0.5 年なら、1 刻みで 5 増えます。流量が負になると、向きと逆に流れます。「負にしない」（`non_negative`）を付けると、負のときは 0 にします
- **ストックの「負にしない」：** ストックに付けると、出ていくフローがストックを 0 より下げません
- **変数：** 刻みごとに計算します。ほかの要素の今の値を使った計算は、変数に分けておくと、図とグラフで中身を確かめやすくなります

## 使えないもの

- **エージェントベースと状態の関数：** `[集団].FindAll()` や `PopulationSize()`、`FindState()`、`Move()` など、エージェント（Population）、状態（State）、遷移（Transition）に関わる関数は使えません。ループサイトはシステムダイナミクスのモデル（ストック、フロー、変数、コンバーター、リンク）だけを扱います
- **人に入力を求める関数：** `Alert()`、`Prompt()`、`Confirm()` は、`is not implemented on this platform` という誤りになります
- **`Pause()`：** 何もしません（シミュレーションは止まらず、値は 0）。止めるときは `Stop()` を使います

## もっと詳しく

このページにない関数（ベクトル、文字列、統計の分布など）と、書き方の細かい決まりは、エンジンの文書 [equations.md](https://github.com/scottfr/simulation/blob/main/equations.md)（英語）にあります。同じものが `node_modules/simulation/equations.md` にも入っています。載っているもののうち、[使えないもの](#使えないもの)に挙げた関数は、ループサイトでは使えません。
