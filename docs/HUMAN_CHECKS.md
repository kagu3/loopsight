# 人の確認が必要なこと

AI（Claude Code）では確かめられないこと、人が決めることをまとめる（2026-10-16 時点）。終わったものは消す。

## ビューア（自分の PC で）

使い方は [VIEWER.md](VIEWER.md) を参照。

- [ ] **使い心地。** ドラッグのしやすさ、文字の大きさ、ウィンドウを狭くしたときの見え方、暗い配色（OS の設定）で読みやすいか。気になったところを AI に伝える

- [ ] **説明資料のフォルダから正式な提案資料が作れるか。** `export_slides` で書き出したフォルダ（`exports/<モデル名>/`）を AI に渡して「このフォルダを元に提案資料を作って」と頼み、`slides.md` と `data/` の CSV から、編集できるグラフ入りの資料（PowerPoint など）ができるか。CSV を Excel で開いて文字化けせず、グラフにできるかもあわせて見る

確かめたのは Windows の Edge（アプリ内のブラウザとヘッドレス）だけ。Chrome、macOS、Linux では試していない。

## 人が決めること

- [ ] **見送った細かい点で困らないか。** レビューで挙がったが、普段の使い方ではほぼ起きないので直していないもの
  - 保存中に別のモデルを開くと、前のモデルのエラーの知らせが、いまのモデルの画面に出ることがある
