## ビューア（自分の PC で）

使い方は [VIEWER.md](../VIEWER.md) を参照。

- [ ] **使い心地。** ドラッグのしやすさ、文字の大きさ、ウィンドウを狭くしたときの見え方、暗い配色（OS の設定）で読みやすいか。気になったところを AI に伝える

- [ ] **書き出した図の SVG を資料に貼って崩れないか。** ビューアの図の書き出すボタン（または AI の `export_diagram`）で書き出した `exports/<モデル名>/diagram.svg` を、PowerPoint や Word に貼り、PDF にもして、拡大したときに矢じりが出ているか、文字が箱からはみ出したり重なったりしないか、日本語が化けないかを見る。SVG を貼れないアプリでは `diagram.png` がぼやけずに使えるかも見る

確かめたのは Windows の Edge（アプリ内のブラウザとヘッドレス）だけ。Chrome、macOS、Linux では試していない。
